Assignment 0: Vector Library

In this assignment, I implemented a vector drawing tool using the <canvas> HTML element.

Using provided files like cuon-matrix-cse160.js, DrawRectangle.html and DrawRectangle.js (now asg0.html and asg0.js, respectively), I implemented a basic webpage where users can input the x and y values for two vectors and draw them on the canvas.

The user can also perform various vector operations, including addition, subtraction, multiplication, division, normalization, magnitude calculation, angle-between calculation, and triangle area calculation.
